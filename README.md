# MAX File Previewer

Мощное Chrome-расширение для корпоративного мессенджера MAX, которое позволяет просматривать, читать и даже запускать отправленные файлы прямо в браузере, избавляя вас от необходимости скачивать их на компьютер.

## ✨ Поддерживаемые форматы

- 📄 **Офисные документы:** `.docx`, `.xlsx`, `.xls`, `.pptx`, `.pdf`, `.rtf`, `.odt`
- 📦 **Архивы:** `.zip` (со встроенным проводником и возможностью предпросмотра файлов прямо из архива)
- 💻 **Исходный код:** `.py`, `.js`, `.c`, `.cpp`, `.java`, `.cs`, `.go`, `.php`, `.rb`, `.swift`, `.ts`, `.sh`, `.html`, `.css`, `.xml`, `.json`, `.md` (с красивой подсветкой синтаксиса)
- 🚀 **Исполняемый код:** `.py` (Python) и `.js` (JavaScript) можно **компилировать и запускать** прямо в браузере с выводом результата в консоль!
- 🎬 **Медиафайлы:** `.mp4`, `.webm`, `.ogg`, `.mp3`, `.wav`
- 🖼 **Изображения:** `.png`, `.jpeg`, `.jpg`
- 📝 **Простой текст:** `.txt`, `.csv`

## 🛠 Установка
1. Откройте вкладку `chrome://extensions/` в вашем браузере.
2. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **Загрузить распакованное расширение** (Load unpacked).
4. Выберите папку с исходным кодом этого расширения.
5. Готово! Теперь при клике на файл в мессенджере MAX он откроется в новой удобной вкладке предпросмотра.

## ⚙️ Особенности
- **Абсолютная безопасность:** Запуск пользовательского кода (`.py`, `.js`) происходит в строгой "песочнице" (sandboxed iframe), что гарантирует отсутствие вредоносного воздействия на расширение или браузер.
- **Поддержка буфера обмена:** Правильное копирование таблиц из Excel-документов (вставляются без искажения HTML разметки).
- **Всё включено:** В случае, если предпросмотр не поддерживается, расширение покажет удобную заглушку с кнопкой для скачивания оригинального файла.

## Проверка изменений

```sh
npm ci
npx playwright install chromium
npm test
```

Проверки запускают расширение в отдельном профиле Chromium и используют локально
сгенерированные PDF, DOCX и ZIP. Проверяются просмотр, распознавание по содержимому,
имена из HTTP-заголовков, cookies, передача `blob:` из MAX частями и ошибки загрузки.
Вход в аккаунт MAX для этих проверок не требуется.

После обновления нажмите «Обновить» на карточке расширения в `chrome://extensions/`
и перезагрузите вкладку MAX. Версия исправления: **1.0.3**.

Файлы загружаются в память браузера для просмотра. Для `blob:` исходная вкладка MAX
должна оставаться открытой. Если вложение хранится на отдельном сервере, при ошибке
загрузки можно разрешить доступ только к адресу этого сервера кнопкой в просмотрщике.
Защищённый PDF запрашивает пароль. Повреждённые файлы, истёкшие ссылки и страницы
авторизации показывают сообщение об ошибке; оригинал можно скачать верхней кнопкой.

В версии 1.0.2 исправлен просмотр Excel: `.xls` читается отдельным парсером,
а для `.xlsx` добавлен резервный импорт при ошибке или зависании конвертера.
Исправлены форматы дат с точками, например `dd.mm.yyyy`, и обмен сообщениями
с табличным просмотрщиком. В резервном режиме сохраняются значения, отображение
чисел и дат, листы и объединения ячеек; сложное оформление может быть упрощено.
Формулы в резервном режиме показывают сохранённый в файле результат, а при его
отсутствии саму формулу. Тесты включают оба формата Excel, пустые листы,
переключение листов, объединения, даты, ошибки конвертера, ZIP и `blob:`.

В версии 1.0.3 исправлены названия при скачивании: имя из чата больше не заменяется
техническим идентификатором сервера. Добавлены разбор `filename*` с языковым полем,
восстановление кириллицы при ошибках кодировки заголовков и определение расширения
по содержимому документа. Кнопка скачивания становится доступна после обработки
файла; выбранное имя закрепляется в обработчике загрузок Chrome.
Архив целиком скачивается из сохранённого в памяти оригинала, в том числе после
просмотра вложенного документа и при исходной ссылке `blob:`.
Проверки скачивания используют обычный механизм Chrome во временном профиле:
проверяются фактические имена на диске и полное совпадение содержимого файлов.
